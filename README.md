# Personal Portfolio Website

## About the Project

This project is a personal portfolio website developed as part of my Web Development Internship at Prodigy Infotech.

The main purpose of this project is to create a professional and visually appealing portfolio that showcases my skills, projects, education, professional experience, and achievements as a software developer.

## Purpose

The purpose of this project is to demonstrate web development and frontend design skills, including:

- Creating a professional portfolio website using HTML
- Designing an attractive user interface using CSS
- Adding interactive features using JavaScript
- Creating a responsive layout for different screen sizes
- Showcasing technical skills and projects
- Providing professional contact information

## How It Works

The portfolio website contains different sections that allow visitors to explore my professional profile.

The website includes:

- Home
- About Me
- Experience
- Skills
- Projects
- Achievements
- Contact

The Home section introduces me with a professional headline, profile photo, and summary.

The About section provides information about my education and academic background.

The Experience section highlights my Web Development Internship at Prodigy Infotech and the projects completed during the internship.

The Skills section displays my technical skills such as Java, Python, SQL, HTML, CSS, and JavaScript.

The Projects section showcases my development and academic projects.

The Achievements section includes my certifications and accomplishments.

The Contact section provides ways to connect with me through email, WhatsApp, GitHub, and LinkedIn.
